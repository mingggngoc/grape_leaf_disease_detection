# Smart Watering / Grape Leaf Disease Detection

The dataset is not uploaded directly to GitHub because it is too large.

Dataset sources:
https://data.mendeley.com/datasets/8nnd2ypcv3/5

  - Black Measles
  - Black Rot
  - Healthy Leaves
  - Isariopsis Leaf Spot
